# Zoo Visitors — Flask Dashboard\n\nThis Flask app inspects a small dataset of daily zoo visitors and provides visualizations and simple predictions.\n\n## Contents\n- `app/` - Flask package with templates, static files, and data\n- `run.py` - quick runner to start the app (`python run.py`)\n- `requirements.txt` - Python dependencies\n\n## Dataset\nFile: `app/data/zoo_visitors.csv`\nRows: 14\nColumns: 2 (date, visitors)\n\n## How to run\n1. Create a virtualenv and install requirements:\n```bash\npython -m venv venv\nsource venv/bin/activate\n```\n2. Install dependencies:\n```bash\npip install -r requirements.txt\n```\n3. Run the app:\n```bash\npython run.py\n```\n4. Open http://127.0.0.1:5000 in your browser\n
